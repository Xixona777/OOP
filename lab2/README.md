# Лабораторная работа №2

**Задание:** реализовать класс `Three` для работы с беззнаковыми целыми троичными числами. Число должно храниться в динамическом массиве `unsigned char`, каждая ячейка содержит цифру 0, 1 или 2. Младшая цифра находится в элементе с индексом 0. Не использовать `std::vector` для внутреннего хранения.

Теория и подробное объяснение кода находятся в [THEORY.pdf](THEORY.pdf). Редактируемая версия отчёта — [THEORY.md](THEORY.md).

## Настройка и сборка в Windows

Для сборки нужны GCC с командой `g++`, CMake и доступ к интернету при первой настройке. CMake автоматически загрузит Google Test, если он не установлен.

Открыть CMD и перейти в каталог проекта:

```bat
cd /d C:\Projects\OOP\lab2
```

Выполнить настройку проекта:

```bat
cmake -S . -B build -DCMAKE_CXX_COMPILER=g++ -DCMAKE_BUILD_TYPE=Release
```

Собрать программу и тесты:

```bat
cmake --build build
```

Запустить тесты:

```bat
ctest --test-dir build --output-on-failure
```

Ожидаемый итог:

```text
100% tests passed, 0 tests failed out of 21
```

## Проверка демонстрационной программы

Запустить программу:

```bat
build\three_demo.exe
```

Ввод с клавиатуры не требуется. Программа выводит:

```text
first = 222
second = 1
sum = 1000
difference = 221
first > second: true
first == second: false
copy = 222
Expected subtraction error: Three subtraction result cannot be negative
```

Все числа в этом примере троичные. Например, `222(3) + 1(3) = 1000(3)`, а `222(3) - 1(3) = 221(3)`.
